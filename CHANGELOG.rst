[0.0.1.0.1.1] - 2024-01-15
--------------------------

Added
~~~~~
- Initial release of Nchantrs framework
- 4 Entry Points: aberration, distortion, nchantment, flection
- YAML-based configuration system
- PyQt5/PySide6 integration
- SQLite backend via FxSQuiRL
- Theme system with QSS templates
- Built-in authentication dialogs
- Model-View architecture (Cape/Cloak/Sigil pattern)
- Comprehensive widget library
- Browser, calendar, calculator widgets
- Table and tree widgets
- Form and control widgets
- Extension/plugin system
- API integration framework
- Multi-database support

Changed
~~~~~~~
- Migrated from legacy Python 2/3 compatibility code
- Updated dependencies to modern versions
- Improved type annotations
- Enhanced error handling

Fixed
~~~~~
- Various bug fixes and improvements
